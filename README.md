# ChuckJokesVue

Actividad 12. Vue 2.7.16 devuelve los cinco textos de la consigna en data() y los representa con v-for y :key. Bootstrap 4.6.2 y una hoja CSS local dan formato a la lista.

Abrir index.html o ejecutar `php -S 127.0.0.1:8913` en esta carpeta. Las librerías son locales. El tag actividad-12 conserva la lista original.
